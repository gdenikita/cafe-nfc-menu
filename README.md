# cafe-nfc-menu

NFC-меню с заказом для заведений. Гость сканирует NFC-метку или QR на столе, выбирает блюда и отправляет заказ. Заказ приходит официантам в Telegram-группу с кнопками «Беру / Готово / Выдано».

## Структура

- `index.html` — страница меню (мобильная, с админкой)
- `worker/worker.js` — сервер (Cloudflare Worker): приём заказов, Telegram, общее меню
- `worker/wrangler.toml` — настройки Worker

## Настройка (по шагам)

### 1. Telegram
1. В Telegram откройте @BotFather, команда `/newbot`, получите **токен**.
2. Создайте группу «Заказы», добавьте бота, официантов и кухню. Сделайте бота администратором.
3. Узнайте `chat_id` группы: напишите в группе любое сообщение, откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":-100...}`.

### 2. Сервер (Cloudflare Workers, бесплатно)
```bash
cd worker
npm install -g wrangler        # один раз
wrangler login
wrangler kv namespace create CAFE      # скопируйте id в wrangler.toml
wrangler secret put BOT_TOKEN          # токен бота
wrangler secret put CHAT_ID            # id группы
wrangler secret put WEBHOOK_SECRET     # любая длинная случайная строка (латиница и цифры)
wrangler secret put ADMIN_PASSWORD     # пароль администратора
wrangler deploy                        # выдаст адрес https://cafe-nfc-menu-api.<имя>.workers.dev
```

### 3. Подключить кнопки Telegram (один раз)
Подставьте свои значения и откройте в терминале:
```bash
curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook" \
  -d "url=https://<АДРЕС_WORKER>/telegram/webhook" \
  -d "secret_token=<WEBHOOK_SECRET>"
```

### 4. Подключить страницу
В `index.html` найдите `apiUrl: ""` и вставьте адрес Worker. Затем в `wrangler.toml` замените `ALLOWED_ORIGIN = "*"` на адрес вашего сайта и выполните `wrangler deploy` ещё раз.

### 5. Столы
Для каждого стола запишите в NFC-метку или сделайте QR-код со ссылкой `https://<ВАШ_САЙТ>/?table=5` (номер меняйте).

### 6. Меню
Откройте сайт, внизу «Вход для администратора», введите пароль. Изменения сохраняются на сервере и видны всем гостям.

## Что умеет страница
- Оплата: наличными, через терминал (официант приносит терминал), онлайн (кнопка пока неактивна, подпись «в разработке»).
- «Позвать официанта» и «Попросить счёт»: в группу приходит сообщение с кнопкой «Иду», повтор с того же стола не чаще раза в минуту.
- «Отзывы и адрес»: кнопки маршрута (Яндекс Карты, Google Карты, 2ГИС, Карты Apple) и отзывов (Яндекс, Google, 2ГИС), телефон, часы работы, пароль Wi-Fi.
- Поиск по меню и стоп-лист (в админке галочка «Нет в наличии»).

## Карты и отзывы: как подключить
Заполните блок `place` в начале скрипта `index.html`:
1. `address`, `phone`, `hours`, `wifiName`, `wifiPass` (пустые поля не показываются).
2. `lat` и `lng`: координаты заведения (в Google Картах нажмите на точку, внизу появится пара чисел).
3. Зарегистрируйте заведение бесплатно в кабинетах: Яндекс Бизнес, Google Business Profile, 2ГИС для бизнеса, Apple Business Connect.
4. Когда карточки появятся, вставьте ссылки: `yandexOrg` (адрес страницы организации в Яндекс Картах), `googleMaps` (кнопка «Поделиться»), `googlePlaceId` (Place ID из Google Business), `gisUrl` (адрес страницы в 2ГИС).
Пока ссылок нет, кнопки открывают поиск по названию и адресу.

## Безопасность
- Токен бота, пароль и ключи bePaid хранятся только в секретах Worker, не в `index.html`.
- Цены считает сервер по сохранённому меню, поэтому гость не сможет подменить сумму.
- Не публикуйте токен бота. Если он где-то засветился, перевыпустите: `/revoke` у @BotFather.

## Онлайн-оплата bePaid (следующий этап)
Заготовка описана в конце `worker/worker.js`. Нужны `shop_id` и `secret_key` заведения. Заказ должен уходить официантам только после подтверждения оплаты от bePaid.

## Ограничения демо-версии
- Заказы хранятся на сервере 48 часов (нужны только для работы кнопок), постоянной истории нет.
- Если два официанта нажмут «Беру» в одну секунду, возможен редкий конфликт. Для большого потока заказов используйте Durable Objects или базу данных.
